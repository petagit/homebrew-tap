# petagit/homebrew-tap

```sh
brew install --cask petagit/tap/prompto-native
```

[Prompto Native](https://promptdeck-wheat.vercel.app/) — a floating 12-key deck
that pastes saved prompts into whatever app you're in. Apple silicon, macOS 13+.

Grant Accessibility once when it asks; that's the permission it pastes with.

## Already have it from the website?

```sh
brew install --cask --adopt petagit/tap/prompto-native
```

`--adopt` takes over the copy already in `/Applications` instead of replacing
it. That matters here: macOS prunes an app's privacy grants the moment its
bundle stops existing, so a plain `--force` install would cost you the
Accessibility permission and you'd re-grant it. Adopting leaves the bundle where
it is.

## Updates

The app updates itself, swapping its own bundle in place for the same reason.
The cask says `auto_updates true` so a routine `brew upgrade` leaves it alone —
don't reach for `--greedy`, which would delete the bundle and take the
permission with it.

## About the signature

The build is signed but not notarised, so the cask strips the quarantine
attribute after installing — what `--no-quarantine` does, without needing to
know to pass it.
