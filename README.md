# petagit/homebrew-tap

Two menu-bar apps for Apple silicon Macs, macOS 13 and newer.

```sh
brew install --cask petagit/tap/peta-whisper
brew install --cask petagit/tap/prompto-native
```

[PETA Whisper](https://peta-whisper.vercel.app/) — hold fn, talk, and the words
appear wherever your cursor is. Bring an OpenRouter key; no subscription.

[Prompto Native](https://promptdeck-wheat.vercel.app/) — a floating 12-key deck
that pastes saved prompts into whatever app you're in.

Both need Accessibility to paste into other apps; grant it once when asked.

## Already have it from the website?

```sh
brew install --cask --adopt petagit/tap/peta-whisper
```

`--adopt` takes over the copy already in `/Applications` instead of replacing
it. That matters here: macOS prunes an app's privacy grants the moment its
bundle stops existing, so a plain `--force` install would cost you the
Accessibility permission and you'd re-grant it. Adopting leaves the bundle where
it is.

## Updates

Both apps update themselves and ask before installing. The casks say
`auto_updates true` so a routine `brew upgrade` leaves them alone — don't reach
for `--greedy`, which would delete the bundle and take the permission with it.

PETA Whisper's builds are ad-hoc signed, so after one of its own updates macOS
may ask you to allow Accessibility and Input Monitoring again. Prompto Native is
signed with a stable identity and keeps its grants across updates.

## About the signature

Neither build is notarised, so each cask strips the quarantine attribute after
installing — what `--no-quarantine` does, without needing to know to pass it.

---

`Casks/peta-whisper.rb` is generated by `homebrew/cask.sh` in the PETA Whisper
repo and published by `site/deploy.sh`. `Casks/prompto-native.rb` is generated
by `mac/homebrew/cask.sh` in the Prompto repo and published by `mac/release.sh`.
Edit them there.
