# petagit/homebrew-tap

```sh
brew install --cask petagit/tap/prompto-native
```

[Prompto Native](https://promptdeck-wheat.vercel.app/) — a floating 12-key deck
that pastes saved prompts into whatever app you're in. Apple silicon, macOS 13+.

Grant Accessibility once when it asks; that's the permission it pastes with.

After the first install the app updates itself, swapping its own bundle in place
so macOS doesn't prune that grant. Brew is told this with `auto_updates true`,
so a routine `brew upgrade` leaves it alone — don't reach for `--greedy`.

`Casks/prompto-native.rb` is generated by `mac/homebrew/cask.sh` in the app's
repo and published by `mac/release.sh`. Edit it there.
